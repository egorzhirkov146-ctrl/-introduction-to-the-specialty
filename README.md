# Веб-калькулятор

## Идея проекта
Простое веб-приложение-калькулятор для выполнения базовых арифметических операций. Пользователь взаимодействует с интерфейсом через браузер, вводя числа и нажимая кнопки. Проект создан в рамках курса по введению в специальность для изучения основ Git, GitHub и веб-разработки.

## Функциональность
- Сложение (+)
- Вычитание (-)
- Умножение (×)
- Деление (÷)
- Очистка поля (C)
- Десятичная точка (.)
- Защита от деления на ноль (выводится сообщение "Ошибка")
- Работа с целыми и дробными числами

## Предполагаемая архитектура

### Frontend (клиентская часть)
- **HTML** — структура страницы (поле ввода, кнопки)
- **CSS** — стилизация и адаптивный дизайн
- **JavaScript** — логика вычислений и обработка событий

### Backend (серверная часть) — опционально
- **Node.js + Express** — для логирования операций
- **База данных (MongoDB)** — для хранения истории вычислений

### Варианты развёртывания
- Локально: открыть `index.html` в браузере
- На сервере: GitHub Pages, Netlify, Vercel
