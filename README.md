# Веб-калькулятор

## Цель проекта
Создать простое, но функциональное веб-приложение-калькулятор для выполнения базовых арифметических операций. Проект реализуется в рамках курса "Введение в специальность" для изучения основ Git, GitHub, веб-технологий и CI/CD.

## Функциональность

### Основные операции
- Сложение (+)
- Вычитание (-)
- Умножение (×)
- Деление (÷)

### Дополнительные возможности
- Защита от деления на ноль (сообщение "Ошибка: деление на ноль")
- Проверка ввода (сообщение "Ошибка: введите числа")
- Адаптивный дизайн (работает на ПК и мобильных устройствах)
- Поддержка клавиатуры (кнопка Enter)

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| Фронтенд | HTML, CSS, JavaScript |
| Бэкенд | Node.js + Express |
| API | REST |
| CI/CD | GitHub Actions |
| Контроль версий | Git |

## Архитектура приложения
Клиент (браузер) → Frontend (HTML/CSS/JS) → API запрос → Backend (Node.js) → Вычисление → Ответ
