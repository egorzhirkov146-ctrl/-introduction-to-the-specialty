# Калькулятор

Это простой консольный калькулятор, который выполняет базовые арифметические операции: сложение, вычитание, умножение и деление. Пользователь вводит два числа и выбирает действие, после чего программа выводит результат. Если пользователь пытается разделить число на ноль, программа выводит сообщение об ошибке и не завершается. Калькулятор работает с целыми и дробными числами. Проект создан в рамках курса по введению в специальность.
