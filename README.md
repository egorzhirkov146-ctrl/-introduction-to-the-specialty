# Веб-калькулятор

## Идея проекта

Простое веб-приложение-калькулятор с фронтендом и бэкендом.

## Функциональность

- Сложение, вычитание, умножение, деление
- Обработка ошибок (деление на ноль, нечисловой ввод)
- Чистый интерфейс

## Архитектура

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- API: POST /api/calculate

## Запуск проекта

1. Установить Node.js
2. Перейти в папку backend
3. Выполнить npm install
4. Выполнить node server.js
5. Открыть http://localhost:3000
