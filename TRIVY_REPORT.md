# Отчёт Trivy: анализ зависимостей и SBOM

## Дата: 2026-04-26

## Инструмент
- **Название:** Trivy
- **Версия:** latest
- **Команда:** `trivy fs --format cyclonedx --output sbom.json .`

## SBOM (Software Bill of Materials)
Файл `sbom.json` содержит все зависимости проекта в формате CycloneDX.

Основные зависимости:
- `express` — веб-фреймворк
- `jest` — тестирование
- `supertest` — тестирование API
- `playwright` — E2E тесты

## CI интеграция
Trivy добавлен в GitHub Actions:
- Генерация SBOM при каждом PR
- Сканирование уязвимостей HIGH/CRITICAL
- Результаты не блокируют merge (учебный режим)
